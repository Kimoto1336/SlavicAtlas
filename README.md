# Атлас народной памяти — ЛР №3

## Проект

**Название:** «Атлас народной памяти».

**Цель работы:** реализовать навигацию между страницами существующего React-приложения, сохранив главную страницу из ЛР №2.

---

## Маршруты приложения

| Адрес | Название страницы | Назначение |
| --- | --- | --- |
| `/` | Главная | Вводная страница проекта и подборка материалов |
| `/encyclopedia` | Энциклопедия | Список материалов, поиск и фильтрация |
| `/encyclopedia/:id` | Материал | Запись каталога, найденная по параметру `id` |
| `/about` | О проекте | Описание цели и структуры проекта |
| `*` | Страница не найдена | Сообщение о неизвестном маршруте и ссылка на главную |

---

## Реализация

- В `src/main.tsx` приложение обёрнуто в `BrowserRouter`.
- В `src/App.tsx` адреса сопоставлены компонентам при помощи `Routes` и `Route`.
- Общие навигация и макет вынесены в `src/components/Layout.tsx`; выбранная страница отображается через `Outlet`.
- В `src/components/Header.tsx` используется `NavLink`, активный раздел выделен стилями.
- В `src/pages/MythologyEntryPage.tsx` параметр `id` читается через `useParams`, а соответствующая запись ищется в mock-данных.
- В `src/pages/EncyclopediaPage.tsx` поиск `q` и фильтр `topic` хранятся в URL через `useSearchParams`.
- `src/components/PageTitle.tsx` использует `useLocation` и `useEffect` для синхронизации заголовка вкладки с текущим адресом.
- `src/components/CurrentAddress.tsx` показывает текущий путь.
- Неизвестный адрес обрабатывается `NotFoundPage`.

## Ручная проверка перед сдачей

- [ ] Открыть `/`, `/encyclopedia` и `/about`; проверить, что на каждой странице одно общее меню.
- [ ] Перейти между страницами по меню и проверить изменение адреса без полной перезагрузки.
- [ ] Открыть `/encyclopedia/perun` и проверить показ записи о Перуне.
- [ ] Открыть `/encyclopedia/unknown-id` и проверить сообщение, что запись не найдена.
- [ ] Открыть `/encyclopedia?q=Перун` и проверить, что поисковое поле и результаты соответствуют адресу.
- [ ] Обновить страницы по прямым адресам и проверить кнопки браузера «Назад» и «Вперёд».
- [ ] Открыть неизвестный путь, например `/unknown`, и проверить сообщение «Страница не найдена» и ссылку на главную.
- [ ] Выполнить `npm install` и `npm run build`.
