# Атлас народной памяти — ЛР №2

React-приложение на React + TypeScript + Vite о славянской мифологии.

Визуальная концепция: тёплый бумажный фон, глубокий зелёный баннер, тонкая орнаментальная графика, крупная антиква и лаконичные карточки.

---

## О проекте

«Атлас народной памяти» — учебное веб-приложение, посвящённое славянской мифологии. Проект объединяет материалы по направлениям в виде энциклопедии с поиском, фильтрами и кратким чтением.

Цель работы — разработать многостраничное SPA на React + TypeScript + Vite с продуманной навигацией и единым визуальным стилем.

---

## Стек технологий

- React — построение пользовательского интерфейса
- TypeScript — типизация кода
- Vite — сборка и dev-сервер
- React Router — маршрутизация между страницами
