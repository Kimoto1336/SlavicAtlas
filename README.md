# Атлас народной памяти — ЛР №2

React-приложение на React + TypeScript + Vite о славянской мифологии.

Визуальная концепция: тёплый бумажный фон, глубокий зелёный баннер, тонкая орнаментальная графика, крупная антиква и лаконичные карточки.

---

## О проекте

«Атлас народной памяти» — учебное веб-приложение, посвящённое славянской мифологии. Проект объединяет материалы по направлениям в виде энциклопедии с поиском, фильтрами и кратким чтением.

Цель работы — разработать многостраничное SPA на React + TypeScript + Vite с продуманной навигацией и единым визуальным стилем.

---

## Стек технологий

- `React — построение пользовательского интерфейса`
- `TypeScript — типизация кода`
- `Vite — сборка и dev-сервер`
- `React Router — маршрутизация между страницами`

---

## Структура

`src/App.tsx — выбор страницы по URL;`
`src/pages/HomePage.tsx — главная страница;`
`src/pages/EncyclopediaPage.tsx — каталог, поиск и тематические фильтры;`
`src/pages/AboutPage.tsx — отдельная страница о проекте;`
`src/components/Header.tsx — навигация сайта;`
`src/components/MythList.tsx и src/components/MythCard.tsx — список и карточка материала;`
`src/mocks/mythologyMock.ts — демонстрационные mock-данные;`
`src/services/mythologyApi.ts — функция получения mock-данных;`
`src/types/mythology.ts — TypeScript-тип записи;`
`src/index.css — оформление и адаптивные стили;`
`docs/lab-02-report.md — отчёт по лабораторной работе.`
`Записи в каталоге — учебные демонстрационные описания, а не полные исторические статьи. Их можно расширять, сохраняя текущую структуру данных..`

## Страницы сайта

### / — Главная

- Вступительный баннер
- Статистика
- Несколько рекомендованных материалов
- Список тем-ссылок

### /encyclopedia — Энциклопедия

- Отдельная энциклопедия со всеми материалами
- Поиск по названию и описанию
- Фильтры по направлениям
- Окно краткого чтения

### /about — О проекте

- Описание идеи
- Принципы каталога
- Технологии

---
Из главной страницы кнопка «Исследовать энциклопедию» открывает /encyclopedia, а «О проекте» открывает /about. Ссылки на тематические строки ведут в каталог с уже выбранным фильтром. Каталог не разворачивается на главной странице.

## Визуальный стиль

- Тёплый бумажный фон
- Глубокий зелёный баннер
- Тонкая орнаментальная графика
- Крупная антиква в заголовках
- Лаконичные карточки материалов
  
---

## Что реализовано

- Адаптивная вёрстка для широких и мобильных экранов;
- Мock-источник с Promise и небольшой задержкой, имитирующей ответ сервера;
- Получение данных через useEffect и хранение их через useState;
- Состояние загрузки и сообщение об ошибке;
- 12 демонстрационных записей в четырёх исходных категориях;
- Поиск и фильтрация энциклопедии по темам;
- Краткое чтение записи в диалоговом окне и добавление записи в избранное;
- Отдельные компоненты `Header`, `MythList`, `MythCard`;
- Самостоятельные страницы `HomePage`, `EncyclopediaPage`, `AboutPage`.

## Установка и запуск

# Запуск 
Требуется установленный Node.js и npm.
`npm install
npm run dev`

# Сборка production-версии
`npm run build`

# Предпросмотр собранной версии
`npm run preview`

# Откройте адрес, который Vite выведет в терминале. Для проверки production-сборки: 
`npm run build`
